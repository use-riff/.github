# Contributing to riff

riff is **not an open source project**. The code, design and brand assets are
proprietary (see each repository's `LICENSE`), and pull requests from outside
contributors aren't accepted.

You can still help in a few ways:

- **Report a problem** with anything public, such as a broken link, a typo or
  a layout bug on the [website](https://use-riff.github.io/). Use the
  *Bug report* issue form.
- **Suggest an idea** for the protocol, artist tools or charity routing. Use
  the *Feature request* form. Explain the problem you want solved, not only
  the solution.
- **Share feedback** on the [roadmap](https://use-riff.github.io/#roadmap) on
  X at [@useRiffPad](https://x.com/useRiffPad).
- **Report a security issue** privately by following
  [SECURITY.md](SECURITY.md). **Don't open a public issue.**

Please search existing issues before opening a new one, and keep each issue
to one problem or idea.

Everyone taking part in riff spaces is expected to follow the
[Code of Conduct](CODE_OF_CONDUCT.md).
