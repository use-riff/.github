# Contributing to riff

Thanks for your interest in riff, a community-coin launch protocol for music.

riff is at an early research and development stage. The protocol isn't live
yet, and most work is still happening internally. There are still useful ways
to help.

## Ways to help

- **Report a problem** with anything public, such as a broken link, a typo or
  a layout bug on the [website](https://use-riff.github.io/). Use the
  *Bug report* issue form in the relevant repository.
- **Suggest an idea** for the protocol, artist tools or charity routing. Use
  the *Feature request* form. Explain the problem you want solved, not only
  the solution.
- **Share feedback** on the [roadmap](https://use-riff.github.io/#roadmap) on
  X at [@useRiffPad](https://x.com/useRiffPad).

Security issues are handled differently. **Don't open a public issue.**
Follow [SECURITY.md](SECURITY.md) instead.

## Before opening an issue

1. Search existing issues to see whether it's already been reported.
2. Keep each issue to one problem or idea.
3. For bugs, include steps to reproduce, what you expected and what happened,
   plus your browser, OS or wallet where it matters.

## Pull requests

Unsolicited pull requests to riff's repositories may not be accepted while the
project is pre-launch. Code, design and brand assets are proprietary (see each
repository's `LICENSE`). For anything beyond a small fix, open an issue first
so it can be discussed.

When you do open a PR:

- Keep it focused on one change, with a clear title.
- Describe what changed and why, and link the related issue.
- Check your change locally. For the website, that means opening
  `index.html` in a browser or serving the folder with
  `python3 -m http.server`, then checking desktop, mobile and a no-JavaScript
  load.
- Fill in the pull request template.

By submitting a contribution, you confirm that you have the right to submit
it and that riff may use it in the project.

## Code of conduct

Everyone taking part in riff spaces is expected to follow the
[Code of Conduct](CODE_OF_CONDUCT.md).
