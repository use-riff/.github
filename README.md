# use-riff/.github

This is the organization-wide `.github` repository for
[**riff**](https://use-riff.github.io/), a community-coin launch protocol for
music being built on Solana.

GitHub treats this repository specially:

- **`profile/README.md`** is shown on the organization's public page at
  <https://github.com/use-riff>.
- **Community health files** here are the defaults for every repository in
  the `use-riff` org that doesn't have its own copy.

## What's in here

| file | purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The public org profile: what riff is, how it works and the roadmap. |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to report bugs, suggest ideas and report security issues. riff is not open source. |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability privately. |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Expected behavior in riff spaces. |
| [`SUPPORT.md`](SUPPORT.md) | Where to ask questions and find project updates. |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Default bug report and feature request forms. |

## Overriding the defaults

A repository that has its own `CONTRIBUTING.md`, `SECURITY.md`,
`.github/ISSUE_TEMPLATE/` and so on uses its own file instead of the one
here. Override a file only when a repository really needs something
different, and keep this repo as the shared baseline.

## Editing the org profile

The profile is plain GitHub-flavored Markdown. Its header image is served
from the public site at
`https://use-riff.github.io/assets/social-card.jpg`, so if that file is
renamed on the site, update the link here too. When the roadmap on the site
changes, update the roadmap table in `profile/README.md` to match.
