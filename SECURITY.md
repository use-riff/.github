# Security policy

riff is a community-coin launch protocol, so security problems can put real
funds at risk. Thank you for reporting them responsibly.

## Status

riff is in research and development and has **not launched on mainnet**.
There is no live riff protocol deployment or official riff coin yet. Treat
any contract, token or site claiming to be a live riff product with
suspicion, and check it against the official channels:

- Website: <https://use-riff.github.io/>
- X: [@useRiffPad](https://x.com/useRiffPad)
- GitHub: <https://github.com/use-riff>

## Reporting a vulnerability

**Please don't report security vulnerabilities in public issues, pull
requests or social media replies.**

Report them privately instead:

1. **Preferred:** use GitHub's private vulnerability reporting. Go to the
   affected repository's **Security** tab and choose **Report a
   vulnerability**.
2. If that option isn't available, send a direct message to
   [@useRiffPad](https://x.com/useRiffPad) on X asking for a private channel.
   Don't include exploit details in that first message.

Helpful things to include:

- the affected repository, component, contract or URL
- a description of the issue and its potential impact
- steps to reproduce, or a proof of concept
- any suggested fix or mitigation

## What to expect

- We'll acknowledge your report as soon as we can.
- We'll keep you updated while we investigate and fix it.
- We ask that you give us reasonable time to fix the issue before sharing it
  publicly. With your permission, we're happy to credit you when it's
  disclosed.

## Scope

In scope:

- code in `use-riff` repositories
- the official website at `use-riff.github.io`
- riff smart contracts and programs, once published

Out of scope:

- third-party wallets, exchanges, networks or services riff doesn't control
- tokens or sites that impersonate riff (please still report them so we can
  warn the community)
- social engineering, spam or denial-of-service testing

Please don't access or change other people's data or funds, and don't
degrade services, while researching an issue.
