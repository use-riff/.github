# Getting help with riff

riff is in research and development and isn't a live product yet, so there's
no end-user support desk. Here's where to go:

| you want to… | go here |
| --- | --- |
| Learn what riff is and see the roadmap | <https://use-riff.github.io/> |
| Follow development and announcements | [@useRiffPad on X](https://x.com/useRiffPad) |
| Report a bug in a public repo or the website | Open an issue using the **Bug report** form |
| Suggest a feature or idea | Open an issue using the **Feature request** form |
| Report a security vulnerability | Follow [SECURITY.md](SECURITY.md). **Not** a public issue. |
| Report a scam or someone impersonating riff | DM [@useRiffPad](https://x.com/useRiffPad) |

riff will never DM you first asking for your seed phrase or private keys, or
asking you to send funds.

Nothing from riff is financial advice. Community coins involve significant
risk and may lose all value.
